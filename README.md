# Jay — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS and JavaScript**.

## About
This portfolio introduces EBENEZER ANJOLAJESU SEMILORE, a Computer Science student at Babcock University and aspiring Front-End Developer interested in FinTech and practical web experiences.

## Features
- Responsive layout for desktop, tablet and mobile
- About, skills, projects, goals and contact sections
- Mobile navigation menu
- Small JavaScript interactions and automatic footer year
- No frameworks or build tools required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Files
- `index.html` — page structure and content
- `style.css` — layout, styling and responsive rules
- `script.js` — mobile navigation and footer year

## Before publishing
Update any details that change, add your preferred professional email and LinkedIn URL, and replace project links with the exact repositories or live demos when available.

## Deploy with GitHub Pages
1. Push these files to your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then save.
5. GitHub will provide your published portfolio URL.


## Live project demonstration
Open `finpay-demo.html` to try the interactive FinPay dashboard. It includes:
- Show/hide account balance
- Searchable transaction history
- Add income or expense transactions
- Automatically recalculated totals
- Resettable sample data

The demo is front-end only. It does not connect to a bank or process real payments.
